## 递归下降 | Recursive descent

:::zh
为每个非终结符写一个函数，函数体照着产生式调用其他函数。手写方便、报错友好，是许多生产编译器的选择。
:::

:::en
Write one function per nonterminal whose body calls the others exactly as the productions say. It is easy to write by hand and gives good error messages, which is why many production compilers use it.
:::

```ts
// expr := term (("+" | "-") term)*
function expr(): Node {
  let left = term();
  while (peek() === "+" || peek() === "-") {
    const op = next();
    left = { op, left, right: term() };
  }
  return left;
}
```

## LL 与 LR | LL and LR

:::zh
LL 分析器自顶向下、从左到右推导，向前看 $k$ 个符号决定用哪条产生式；LR 分析器自底向上，把输入移进栈中，在栈顶匹配到产生式右部时归约。LR 能处理的文法更多，通常由工具生成。
:::

:::en
LL parsers work top-down and predict which production to use from $k$ tokens of lookahead; LR parsers work bottom-up, shifting input onto a stack and reducing when its top matches a right-hand side. LR handles more grammars and is usually generated by a tool.
:::
